Soporte de Titan

Titan es un cliente SSH para iPhone y iPad. Si algo no funciona o tienes una idea, escríbenos a neuralbeat.dev@gmail.com y te respondemos lo antes posible.

Primeros pasos

  • Tu servidor necesita tener SSH activo (en Linux, el paquete openssh-server).
  • En Titan pulsa + y rellena dirección, puerto (22), usuario y contraseña o clave.
  • Para usar clave: créala en Llaves e instálala en el servidor desde ahí.
  • No hace falta instalar nada más en el servidor.

Si no conecta

  • Comprueba que el servidor responde por SSH desde otro equipo y que el puerto está abierto.
  • En red local, permite el acceso a la red local cuando iOS lo pida.
  • Si cambió la huella del servidor, Titan avisa y rechaza la conexión por seguridad.

Titan Support

Titan is an SSH client for iPhone and iPad. If something does not work or you have an idea, write to neuralbeat.dev@gmail.com and we will reply as soon as we can.

Getting started

  • Your server needs SSH running (on Linux, the openssh-server package).
  • In Titan tap + and fill in address, port (22), user, and a password or key.
  • To use a key: create it in Keys and install it on the server from there.
  • Nothing else needs to be installed on the server.

If it won't connect

  • Check that the server answers SSH from another machine and the port is open.
  • On a local network, allow local network access when iOS asks.
  • If the server's fingerprint changed, Titan warns you and refuses the connection for safety.
